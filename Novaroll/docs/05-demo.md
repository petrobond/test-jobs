# Мини-демо (вход → выход)

Ниже — сценарий скринкаста/скриншотов «вход → выход» и текстовое описание того, что видно.

## Что показать
1. **Вкладка «Извлечь карточку».**
   - Выбрать пример из набора → «Загрузить пример».
   - Нажать «Извлечь карточку».
   - Справа появится карточка: таблица полей, шкала уверенности, зелёная плашка
     «можно заносить в CRM» (или жёлтая «требует проверки»).
   - Раскрыть «Подтверждения (цитаты из письма)» — под каждое поле видна цитата.
   - Раскрыть «JSON карточки» — готовый к интеграции формат.
2. **Вкладка «Eval».**
   - Сводные метрики: писем, JSON-валидных, галлюцинации, стоимость/письмо.
   - Таблица «Сверка с целями» (факт vs цель, ✅/❌).
   - Таблица точности по полям.
3. **Вкладка «О решении».** Кратко: как работает, где какие LLM, порог уверенности.

## Пример входа (из golden set)
```
Тема: Запрос КП на поставку ноутбуков
Здравствуйте! Меня зовут Мария Соколова, компания ООО Ромашка-Логистик.
Нужно КП на поставку 50 ноутбуков для нового офиса. Это срочно,
нужно до конца недели, желательно к 2026-10-20.
Контакт: m.sokolova@romashka-example.com, тел. +7 999 123-45-67.
```

## Как сделать скриншоты
1. Поднять приложение (`streamlit run app/streamlit_app.py` или `docker compose up`).
2. Сделать 3 скриншота: вход+карточка, вкладка Eval, JSON карточки.
3. Положить в `docs/` (в этом репозитории скриншоты не хранятся — доложить при отправке тестового).
