# Кейс A. Письмо → карточка CRM — постановка

## Боль
Менеджеры вручную переносят данные из входящих писем в CRM: копируют компанию, контакт,
суть запроса, продукт и срочность. Это медленно и приводит к ошибкам: опечатки в e-mail/телефоне,
перепутанные поля, потерянные заявки. Каждая ошибка — неверная карточка и риск потерять клиента.

## Ценность для бизнеса
- Ручной перенос письма ~2–3 минуты → секунды; при 50 письмах/день экономия ~1.5–2 ч на человека.
- Меньше ошибок ввода: поля заполняются единообразно и проверяются (формат, подтверждение цитатой).
- Спорные карточки не «улетают» в CRM молча: у каждой есть уверенность и флаг «проверить вручную».
- В промпт уходит только нужный текст, ПДн не размножаются между системами.

## Вход
Сырой текст входящего письма (одним блоком): тема, тело, подпись, возможные пересланные ветки.

## Выход (карточка CRM)
Обязательные поля из ТЗ + служебные:

| Поле | Тип | Назначение |
|---|---|---|
| `company` | string \| null | компания из ТЗ |
| `contact_name` | string \| null | контакт из ТЗ |
| `contact_email` | string \| null | контакт из ТЗ |
| `contact_phone` | string \| null | контакт из ТЗ |
| `request_summary` | string | суть запроса из ТЗ |
| `product` | string \| null | продукт из ТЗ |
| `urgency` | `low` \| `medium` \| `high` | срочность из ТЗ |
| `requested_deadline` | ISO-дата \| null | желаемый срок |
| `language` | код языка | ru/en/… |
| `confidence` | 0..1 | уверенность модели |
| `evidence` | поле → цитата | подтверждение значения из письма |
| `missing_fields` | список | чего не нашлось |
| `needs_review` | bool | флаг «человек, проверь» |

## Критерий «готово» (acceptance)
Черновик считаем годным, если на eval-сете одновременно выполнено:

| Метрика | Цель |
|---|---|
| JSON-валидность карточек | ≥ 98% |
| Точность `company`, `contact_name`, `contact_email` | ≥ 95% |
| Точность `contact_phone` | ≥ 90% |
| Точность `product`, `urgency`, `requested_deadline` | ≥ 90% |
| Полнота по присутствующим в эталоне полям | ≥ 95% |
| Recall ошибок флагом `needs_review` | ≥ 90% |
| Доля ложных тревог `needs_review` | ≤ 30% |
| Галлюцинации (значение без подтверждения в письме) | ≤ 2% |
| Латентность p95 | ≤ 8 c |
| Стоимость | ≤ $0.005 / письмо |

## Что вне проекта (осознанно)
- Реальная интеграция с конкретной CRM (Bitrix/amo) — за рамками черновика, формат выхода JSON готов к маппингу.
- Вложения (PDF/DOCX) — не парсятся; берём текстовое тело письма.
- Многоязычная тонкость формулировок срочности — упрощена до правил + LLM.
